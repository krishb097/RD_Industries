# 🚀 RD - Industries | Next-Gen Enterprise Tech Platform

A modern, responsive, mobile-first web application designed for **RD - Industries** — a digital agency providing Web Designing, Custom Web Development, Programming, and Technical Consulting.

This platform features protected user modules, real-time WebRTC live video calling, a built-in browser-based IDE workspace, and accurate date-based workspace analytics.

---

## ✨ Features & Modules

- **🎨 Metallic Dark UI/UX**: Custom design system crafted around the official RD-Industries brand aesthetic with fluid transitions and smooth micro-interactions.
- **🔐 Strict Authentication Lock**: Guest users can explore the Home/Landing page, while core engineering modules require authentication (`login.html` & `signup.html`).
- **📹 Real-Time WebRTC Video Call Studio**: Direct peer-to-peer live video and audio consultation channel powered by **PeerJS** for client-to-admin meetings.
- **💻 Browser Workspace IDE**: Multi-tab code editor (`HTML`, `CSS`, `JS`) with real-time compilation, live preview frame, and terminal debugger console.
- **📈 Daily Real Work Analytics**: Dynamic Chart.js dashboard tracking actual workspace activity points per date without fake curve generation.
- **🤝 Lead Referral System**: Dedicated module for client referrals synced directly to the Admin Portal.
- **🛡️ Standalone Executive Admin Command Center (`admin.html`)**: Centralized portal for monitoring registered users, initiating WebRTC video calls, reviewing synced IDE codes, and direct WhatsApp/Phone outreach for referral leads.
